## ✨ Features / Основные возможности

### 📐 Math Module / Математика
* **[EN] Smart Word Problem Solver:** Analyzes tasks and draws a school-style layout using a custom curly brace block (`├─ ? total`). Generates step-by-step long division.
* **[RU] ИИ-Решитель задач:** Считает текстовые задачи, выдаёт пошаговый разбор и строит Дано с НАСТОЯЩЕЙ ФИГУРНОЙ СКОБКОЙ (`├─`). Делит числа в столбик ровными линиями.

### 🌐 Languages & Spotlight / Языковые модули
* **[EN] Spotlight Textbook Integration:** Local dictionary featuring characters, vocabulary, and professions from Spotlight (Grades 1–7) with autonomous Levenshtein typo-correction.
* **[RU] Вселенная Spotlight:** Вшита база слов, героев и тем из учебников Spotlight за 1–7 классы. Поиск опечаток по буквам работает полностью автономно.

### 🎥 Visuals & UX / Интерфейс и Копирование
* **[EN] Gaming-Style Splash:** Features an animated intro window (**LUKWA STUDIOS X GEMINI**) that smoothly fades out (*Fade Out effect*) on launch. Supports full text selection, `Ctrl+C`, and Desktop `.txt` exports.
